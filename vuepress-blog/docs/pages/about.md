# 关于

## 博主介绍

你好！欢迎来到码霖汤姆的博客。

我是一名前端开发者，热爱技术，喜欢分享。这个博客主要记录我的学习心得和技术文章。

## 技术栈

### 前端

- **框架**：Vue.js, React
- **语言**：JavaScript, TypeScript
- **构建工具**：Vite, Webpack
- **CSS**：SCSS, Tailwind CSS

### 后端

- **运行时**：Node.js
- **数据库**：MySQL, MongoDB
- **部署**：Docker, GitHub Actions

## 博客技术

这个博客使用以下技术构建：

- **VuePress 2**：基于 Vue 3 的静态网站生成器
- **Vue 3**：渐进式 JavaScript 框架
- **Vite**：下一代前端构建工具
- **Pinia**：Vue 的状态管理库
- **GitHub Pages**：免费的静态网站托管
