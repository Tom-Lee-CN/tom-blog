# Markdown 写作指南

Markdown 是一种轻量级标记语言，让你可以使用纯文本格式编写文档。本文将介绍 Markdown 的常用语法。

## 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 强调

```markdown
**粗体文本**
*斜体文本*
***粗斜体文本***
~~删除线文本~~
```

### 列表

**无序列表：**
```markdown
- 列表项 1
- 列表项 2
  - 嵌套列表项
```

**有序列表：**
```markdown
1. 列表项 1
2. 列表项 2
   1. 嵌套列表项
```

**任务列表：**
```markdown
- [x] 已完成任务
- [ ] 待完成任务
- [ ] 另一个待完成任务
```

### 链接和图片

```markdown
[链接文本](https://example.com)
[带标题的链接](https://example.com "链接标题")

![图片描述](image.jpg)
![带标题的图片](image.jpg "图片标题")
```

### 代码

**行内代码：**
```markdown
使用 `code` 标签包裹代码
```

**代码块：**
````markdown
```javascript
function hello() {
  console.log('Hello World!')
}
```
````

### 引用

```markdown
> 这是一段引用文本
> 
> 可以包含多段内容
```

### 表格

```markdown
| 列 1 | 列 2 | 列 3 |
|------|------|------|
| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |
```

### 分割线

```markdown
---
***
___
```

## 高级语法

### 数学公式

行内公式：$E = mc^2$

块级公式：
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

### 脚注

```markdown
这里有一个脚注[^1]。

[^1]: 这是脚注内容。
```

### 定义列表

```markdown
术语 1
: 定义 1

术语 2
: 定义 2
```

### 待办事项

```markdown
- [x] 已完成
- [ ] 待完成
```

## 写作技巧

### 1. 结构清晰

- 使用标题层级组织内容
- 每个章节只讨论一个主题
- 使用列表和表格整理信息

### 2. 代码规范

- 为代码块指定语言以获得语法高亮
- 保持代码缩进一致
- 添加必要的注释

### 3. 图片优化

- 使用描述性的图片标题
- 压缩图片大小
- 考虑响应式图片

### 4. 链接管理

- 使用有意义的链接文本
- 检查链接有效性
- 考虑使用相对链接

## 工具推荐

### 编辑器

- **VS Code**：配合 Markdown 插件
- **Typora**：所见即所得编辑器
- **Obsidian**：知识管理工具

### 预览工具

- **Markdown Preview**：VS Code 插件
- **Mark Text**：桌面预览工具
- **在线预览**：各种在线 Markdown 编辑器

### 格式化工具

- **Prettier**：代码格式化
- **markdownlint**：Markdown 语法检查

## 总结

Markdown 是一种简单而强大的标记语言，适合编写技术文档、博客文章等。掌握 Markdown 语法能大大提高写作效率。

建议多练习，熟练掌握各种语法，并形成自己的写作风格。
